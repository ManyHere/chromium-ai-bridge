# Browser Bridge Skill (v1.1)

Используйте этот навык, когда пользователь хочет взаимодействовать со своим реальным браузером Chromium (Chrome, Edge, Brave, Яндекс Браузер и др.).

## Ключевые слова активации:
- `/browser` или `/browser-bridge`
- "в браузере", "посмотри в браузере", "что у меня открыто в браузере"
- "кликни на ...", "заполни форму в браузере", "сделай скриншот вкладки"

## Доступные инструменты (MCP: chromium-browser):
1. `browser_read_page`: **Основной инструмент.** Получить сжатый текст страницы и список интерактивных элементов `[1]`, `[2]` (с приоритетом модальных окон и видимого экрана).
2. `browser_click`: Мгновенно кликнуть по номеру элемента (`"1"`), тексту кнопки или CSS-селектору.
3. `browser_type`: Ввести текст в `<input>`, `<textarea>` или `contenteditable`-редактор (поддерживает React/Vue/Next.js и `press_enter=True`).
4. `browser_press_key`: Нажать клавишу (`Escape` для закрытия модалок, `Enter`, `Tab`, `ArrowDown`, `Space`).
5. `browser_select_option`: Выбрать пункт в `<select>` по значению или тексту.
6. `browser_scroll`: Прокрутить страницу (`down`, `up`, `top`, `bottom`) или к элементу.
7. `browser_get_active_tab` / `browser_list_tabs`: Информация об активной или всех открытых вкладках.
8. `browser_open_tab` / `browser_navigate` / `browser_switch_tab` / `browser_close_tab`: Управление вкладками и переходами (с автоожиданием загрузки).
9. `browser_reload` / `browser_go_back` / `browser_go_forward`: Обновление и навигация по истории вкладки.
10. `browser_eval_js`: Выполнить JavaScript в контексте страницы (`MAIN` world с CSP-фолбэком для простых селекторов).
11. `browser_download_file`: Скачать файл по URL с использованием авторизованной сессии/кук браузера прямо на диск.
12. `browser_screenshot`: **ТОЛЬКО РЕЗЕРВНЫЙ РЕЖИМ!** Делает PNG-скриншот экрана и передает изображение модели.

## Строгие правила работы (Алгоритм скорости):
1. **Всегда начинайте с `browser_read_page`**: Это ультра-быстрый текстовый режим (~0.2 сек), не тратящий токены на картинки.
2. **Действуйте по числовым ID**: Вызывайте `browser_click("5")` или `browser_type("3", "текст")`, передавая номер из `browser_read_page`.
3. **Скриншоты (`browser_screenshot`) — строго при проблемах**: **НИКОГДА** не вызывайте `browser_screenshot` при обычной работе! Вызывайте его **только тогда**, когда в обычном текстовом режиме возникла проблема (элемент не находится в DOM, интерфейс отрисован на `<canvas>`, сложный визуальный виджет, капча, клик не сработал) или когда пользователь сам явно попросил сделать скриншот.
